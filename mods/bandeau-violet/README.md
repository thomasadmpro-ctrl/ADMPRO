# bandeau-violet 💜

Bandeau noir et violet affiché au-dessus du prompt de Claude Code. Il montre en permanence :

- 💜 le **projet en cours** (nom du dossier de travail) ;
- ⚡ / ✅ l'**état** : en cours ou prêt ;
- ⏱️ la **durée du dernier tour** ;
- 🛠️ le **nombre d'outils** utilisés pendant ce tour.

## Utilisation

- Bouton **Masquer** pour le cacher, commande **`/bandeau`** pour l'afficher ou le masquer.
- Surfaces : terminal et app de bureau (le bandeau au-dessus du prompt n'existe pas sur mobile).
- Aucun son, aucune configuration nécessaire.

## Installation

Dans Claude Code (terminal) :

```
/plugin install bandeau-violet --marketplace thomasadmpro-ctrl/ADMPRO
```

Depuis un shell :

```
claude plugin install bandeau-violet --marketplace thomasadmpro-ctrl/ADMPRO
```

Dans l'app de bureau : clic sur **+** à côté du prompt → **Plugins** → **Add marketplace** avec `thomasadmpro-ctrl/ADMPRO` → **Add plugin**.
