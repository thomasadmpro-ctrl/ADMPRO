# panneau-notes 💜

Panneau latéral noir et violet à côté du chat : les **notes du projet en cours** (un carnet par dossier de projet), gardées d'une session à l'autre.

- Ajouter : champ « Nouvelle note… » dans le panneau (terminal, desktop, VS Code) ou **`/note ton texte`** (partout, mobile compris).
- Supprimer : bouton **✕** à côté de la note.
- Rouvrir le panneau : **`/notes`**. Le fermer : sa croix ou Échap.
- Sur un terminal étroit (moins de ~144 colonnes), le panneau ne s'ouvre qu'avec `/notes`.

## Installation

Dans Claude Code (terminal) :

```
/plugin marketplace update admpro-mods
/plugin install panneau-notes@admpro-mods
```

Puis relancer `claude`.
