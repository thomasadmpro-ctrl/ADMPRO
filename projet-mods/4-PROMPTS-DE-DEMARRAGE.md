# Prompts de démarrage — à copier-coller

> Chaque conversation = un objectif. Commence par un de ces modèles, remplace les `<…>`.

## Créer un nouveau mod

```
Nouveau mod : <ce que je veux voir ou qui doit se passer>.
Où : <panneau à côté / bandeau au-dessus du prompt / ligne de statut / notification / commande /xxx>.
Quand : <toujours / quand je lance une commande / à la fin de chaque réponse / …>.
Surface prioritaire : <desktop / mobile / terminal / vscode>.
Exemple concret de ce que je veux voir : <…>
```

## Modifier un mod existant

```
Modifie le mod « <nom> » : <changement voulu>.
Ce qui ne va pas aujourd'hui : <…>
Garde : <ce qui doit rester identique>.
```

## Un mod ne marche pas

```
Le mod « <nom> » ne fonctionne pas : <ce que je vois / message d'erreur copié>.
Ce que j'attendais : <…>
Diagnostique la cause avant de corriger.
```

## Réinstaller mes mods dans cette session

```
Recharge mes mods sauvegardés dans mods/ pour cette session (tous / seulement : <noms>).
```

## Faire le point

```
Liste mes mods (mods/INDEX.md), dis-moi lesquels se chevauchent ou pourraient être améliorés, et propose 3 idées de nouveaux mods adaptés à mon profil.
```

## Idées de mods pour démarrer

- **Bandeau de contexte** : rappel permanent du projet / client en cours au-dessus du prompt.
- **Panneau notes** : un bloc-notes à côté du chat, gardé entre les sessions.
- **Compteur de tour** : durée et nombre d'outils utilisés à chaque réponse.
- **Garde-fou** : bloquer ou demander confirmation avant certaines commandes (`rm`, `git push`…).
- **Commande `/devis`** : génère un gabarit de devis (ex. montage PC) prêt à remplir.
- **Son de fin** : petit son quand une longue réponse se termine.
